# 배포·게시 체크리스트 (TeamCP)

> 2026-11-26 결정: **실제 스토어 게시가 확정되기 전까지는 사이트에 상품 코드(카드·타일·사이트맵 등재)를 올리지 않는다.**

## 1. 미게시 상품 코드 미등재 규칙 (신규)

- 사이트(포털 index, 게임/앱 목록, 타일 문구, sitemap.xml)에는 **실제 게시가 확인된 제품만** 등재한다.
- '출시 예정', '출시 준비 중', 'Coming soon' 같은 게시 예정 표기·카드를 새로 추가하지 않는다. 준비 중 안내가 필요하면 표기를 통일한다 — 한국어 **'준비 중입니다'**, 영어 **'Coming later.'**
- 미게시 제품이라도 개인정보처리방침 페이지와 그 경로는 **삭제·이동하지 않는다**(스토어 심사·데이터 삭제 안내용). 고객지원 페이지의 제품별 방침 링크도 그대로 유지한다.
- 기존 공개 주소(154개)는 유지한다 — 목록에서 빠지는 것이지 페이지가 사라지는 것이 아니다.
- app-ads.txt는 바이트 단위 보존(임의 수정 금지).

## 2. 게시 확정 시 사이트 코드 등재 절차 (체크리스트)

- [ ] **실제 신규 공개(게시) 확인**: 스토어 콘솔의 게시 상태와 스토어 URL 접속 가능 여부를 확인한다. 이 확인 없이는 사이트에 코드를 추가하지 않는다.
- [ ] 게임: games/index.html·en/games/index.html 의 '출시 게임 / Available now' 섹션에 카드 추가(스토어 링크 포함).
- [ ] 앱: apps/index.html·en/apps/index.html 에 카드 추가(라벨 없이 스토어 링크 포함)하고 '준비 중입니다 / Coming later.' 안내를 제거.
- [ ] 포털(index.html·en/index.html) 타일·추천 영역 반영 여부 결정.
- [ ] sitemap.xml에 상세 URL 추가(한국어·영어).
- [ ] 커밋 메시지에 제품명·스토어를 명시하고 push, 배포 후 라이브 URL 최종 확인.

- [ ] `git diff --diff-filter=D --name-only` 출력 **없음**(파일 삭제 금지).
